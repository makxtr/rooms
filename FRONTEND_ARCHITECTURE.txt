# Chats - Frontend Architecture

```
assets/
├── js/
│   ├── app.js              # Entry point, dynamic module loading
│   ├── utility.js          # Utils (Template, Router)
│   ├── events.js           # Event system
│   ├── rest.js             # REST API client
│   ├── user_socket.js      # WebSocket (Phoenix Channels)
│   ├── models/
│   │   ├── main.js         # Me, Socket
│   │   ├── rooms.js        # Rooms management
│   │   ├── room.js         # Single room
│   │   ├── roles.js        # User roles
│   │   └── userpics.js     # Avatars
│   └── views/
│       ├── about.js        # Home page
│       ├── room.js         # Room interface
│       ├── side.js         # Sidebar
│       ├── hall.js         # Rooms list
│       ├── talk.js         # Chat
│       ├── reply.js        # Replies
│       ├── settings.js     # Settings
│       ├── profile.js      # Profile
│       ├── moderate.js     # Moderation
│       ├── admin.js        # Admin panel
│       ├── ranks.js        # Ranks
│       └── datepicker.js   # Calendar
└── css/
    └── app.css             # Single CSS bundle

lib/chats_web/
├── components/layouts/
│   └── root.html.heex      # Root layout (CSS/JS includes)
└── controllers/page_html/
    └── home.html.heex      # HTML markup (#about, #rooms)
```

## Architecture

**Type:** Vanilla JavaScript SPA + Phoenix backend
**Routing:** Hash-based (#/room/abc123)
**Communication:** WebSocket (real-time) + REST API

### Loading flow:
1. `app.js` loads jQuery from CDN
2. Sequential module imports: utility → events → rest → models → views → user_socket
3. FastClick initialization for mobile devices

### Global objects:
- `Events` - event system
- `Template` - template engine
- `Router` - hash routing
- `Rest` - REST API client
- `Me` - current session
- `Socket` - WebSocket connection
- `Rooms` - rooms management
- `$window`, `$document` - jQuery wrappers

### API Endpoints:
```
GET  /api/health          # Health check
GET  /api/sessions/me     # Current session
GET  /api/rooms/:hash     # Room data
POST /api/rooms           # Create room
GET  /api/messages        # Message history
POST /api/messages        # Send message
POST /api/sockets         # WebSocket connection
```

## Tech Stack

**Frontend:**
- Vanilla JavaScript (ES6 modules)
- jQuery 3.2.1 (CDN)
- Custom template engine
- FastClick
- Phoenix Channels (WebSocket)

**Backend:**
- Phoenix Framework (Elixir)
- HEEX templates (server-side rendering)

## Features

- Event-driven architecture
- Async module loading via `import()`
- Component communication via event system
- Real-time via WebSocket
- Progressive enhancement (HTML works without JS)
